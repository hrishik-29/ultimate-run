# Ultimate Run

## Overview
Ultimate Run is an engaging, fast-paced endless runner game project. This repository contains the developmental files, game assets, and demonstration videos for the game's mechanics and level design.

> **Note:** This project is currently a work-in-progress (WIP).

## Features
- **Dynamic Gameplay**: Fast-paced obstacle dodging and scoring system.
- **Level Design**: Evolving difficulty as the player progresses.
- **Assets & Scripts**: Contained within the `ultimate_run` directory.

## Project Structure
- `ultimate_run/`: The main source code, assets, and project files.
- `ultimate run demo 2 - Made with Clipchamp.mp4`: Gameplay demonstration showcasing movement mechanics, environment design, and core game loops.
- `Lazy Day Challenge.pdf`: Project documentation or related challenge details.

## Getting Started

### Prerequisites
- Depending on the engine used (e.g., Unity, Godot), ensure the respective game engine is installed.

### Installation & Usage
1. Open the game engine.
2. Load the project from the `ultimate_run` directory.
3. Open the main scene and click Play to test the mechanics.
4. For a quick preview, watch the included `.mp4` video.
